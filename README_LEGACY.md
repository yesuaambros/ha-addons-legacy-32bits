# Home Assistant Legacy 32-bit Add-ons

Repositorio combinado creado a partir de:
- home-assistant/addons commit 93b9a8e31283caa63fd72b66a4158dc91f221171
- zigbee2mqtt/hassio-zigbee2mqtt versión 2.7.1-1

Uso:
1. Subir el contenido de esta carpeta a un repositorio público de GitHub.
2. Editar repository.yaml y repository.json cambiando TU_USUARIO por el usuario real.
3. Añadir la URL del repositorio en Home Assistant:
   Ajustes > Complementos > Tienda de complementos > tres puntos > Repositorios.
